Beyond the basic requirements

Website Enhancements

MY Plant Watch uses several HTML5 and CSS techniques to improve navigation, presentation, usability and the way plant information is explored. The four enhancements below are implemented without JavaScript and link directly to examples within the website.

Implemented features

Four enhancements used across the site

Each enhancement extends the standard page layout with additional responsive, interactive or accessibility-focused behaviour. The technical notes name the main HTML or CSS techniques used.

01

Navigation enhancement

CSS-only responsive hamburger navigation

The full desktop navigation is replaced before it becomes crowded or wraps onto a second line. On smaller screens a native HTML <details> and <summary> menu becomes available instead. The three hamburger lines transform into an X while the menu is open.

How it extends the basic site

This provides a compact mobile navigation system without JavaScript. A media query changes which navigation is displayed, while CSS transforms animate the hamburger icon and the mobile menu remains keyboard accessible because it uses native HTML controls.

<details> / <summary> @media transform :focus-visible
View responsive navigation →
02

Form usability enhancement

Dynamic HTML5 validation feedback

The website's forms combine native HTML5 validation with CSS feedback so visitors can see when an entered value matches the required format. Instructional hints also change appearance when an input is invalid.

How it extends the basic site

Required fields use HTML attributes such as pattern, maxlength and required, while CSS pseudo-classes including :valid, :invalid and :placeholder-shown provide immediate visual feedback without JavaScript.

:valid / :invalid :placeholder-shown pattern required
View form feedback →
03

Information-design enhancement

Interactive plant classification tree

The Explorer converts the Family → Genus → Species hierarchy into a visual tree. Each family, genus and species is represented by a styled node that links directly to the related information page. This makes the taxonomic relationships easier to understand than a plain list of links.

How it extends the basic site

CSS Grid creates the branching layout, pseudo-elements provide directional arrows, and hover/focus states give each node interactive feedback. At narrower screen sizes the layout reorganises into a vertical structure so the relationships remain readable without horizontal scrolling.

CSS Grid ::after responsive breakpoints hover / focus states
View classification tree →
04

Usability enhancement

Sticky contextual form guidance

The Contribution and Enquiry pages keep their instructions visible beside the form while a user scrolls through longer input sections. This reduces the need to scroll back to the top to check what information is expected.

How it extends the basic site

The help panel uses position: sticky with an offset that accounts for the sticky site header. At smaller screen sizes, a media query returns the panel to normal document flow so it does not reduce the available width of the form.

position: sticky CSS Grid @media responsive fallback
