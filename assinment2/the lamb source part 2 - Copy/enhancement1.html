HTML5 and CSS features

Website Enhancements

MY Plant Watch uses responsive layouts, CSS interaction, animation and native HTML controls to make the website easier to navigate and more engaging without JavaScript.

Implemented features

Enhancements used across the website

The features below are implemented with HTML5 and CSS. Each item links to a page where the behaviour can be tested directly.

01

Responsive layout

Fluid page layout

Page widths, grids, typography and spacing adapt as the browser becomes wider or narrower instead of relying on one fixed desktop size.

How it works

Relative widths, min() , clamp() , CSS Grid, Flexbox and media queries allow sections and cards to resize or stack naturally on smaller screens.

min() clamp() CSS Grid Flexbox @media

Where to find it

Homepage · Featured species

Try it

Resize the browser: the image collage and text stack vertically on a narrow screen.

Open this feature →
02

Navigation

CSS-only responsive hamburger menu

The full navigation is replaced by a compact hamburger menu before the links become crowded on smaller screens.

How it works

A native <details> / <summary> control opens the mobile menu while CSS transforms the three hamburger lines into a close icon.

<details> <summary> transform @media

Where to find it

All pages · top navigation

Try it

Narrow the browser to a phone width, then select the three-line menu. Use Tab and Enter to open it with the keyboard.

Open this feature →
03

Image interaction

Featured-picture hover focus

Hovering or keyboard-focusing a featured plant photograph makes that image slightly larger and brings it visually in front of the surrounding pictures.

How it works

CSS :hover and :focus-visible states change transform , shadow and stacking order so the selected image becomes more prominent.

:hover :focus-visible transform z-index

Where to find it

Homepage · Featured species

Try it

Hover a plant image or reach it with Tab. Its image and matching description become prominent.

Open this feature →
04

Form feedback

Error hints that change with the input

Form error guidance remains hidden while a field is untouched or valid. If the visitor enters an invalid value, the field styling changes and an error-specific message appears below it.

How it works

HTML attributes such as pattern , required and maxlength define valid input. CSS uses :invalid and :placeholder-shown to reveal the matching error hint.

:invalid :placeholder-shown pattern required

Where to find it

Contribution form · Your name

Try it

Enter 123 in the name field. The error hint appears; replace it with letters and the hint disappears.

Open this feature →
05

Navigation and guidance

Sticky navigation and form guidance

The main navigation remains available at the top of the screen while scrolling. On longer forms, the guidance panel also stays visible beside the input fields.

How it works

Both features use position: sticky with different top offsets and stacking levels. On narrow screens the form guide returns to normal document flow.

position: sticky top z-index responsive fallback

Where to find it

Contribution form · A useful observation

Try it

On a wide screen, scroll through the form. The guide stays beside the fields while the site navigation stays at the top.

Open this feature →
06

Interface feedback

Button hover and focus effects

Buttons and important links respond visually when the pointer moves over them or when they receive keyboard focus.

How it works

CSS transitions smoothly change background colour, position and other visual properties, making interactive controls easier to recognise.

:hover :focus-visible transition transform

Where to find it

Homepage · Explore Plants button

Try it

Hover the Explore Plants button or select it with Tab to see its interactive state.

Open this feature →
07

Automatic featured content

Automatic featured-species collage with changing text

The homepage featured-species collage changes its focused photograph automatically while idle. The accompanying family, species name and description change in sync with the focused image.

How it works

Coordinated CSS keyframe animations control image emphasis and description opacity. Hover or keyboard focus pauses the automatic sequence and lets the visitor choose a plant directly.

@keyframes opacity transform animation-play-state

Where to find it

Homepage · Featured species

Try it

Leave the collage idle to watch the picture emphasis and description change together. Hover or focus a photograph to select a plant.

Open this feature →
08

Hero animation

Changing homepage hero pictures

The homepage hero cycles through several plant backgrounds instead of displaying one permanent image, while a dark overlay keeps the heading readable.

How it works

Multiple absolutely positioned background layers use delayed CSS opacity animations so each image fades in and out in sequence.

@keyframes animation-delay opacity background-image

Where to find it

Homepage · opening banner

Try it

Watch the background fade between four plant images. Reduced-motion settings keep a static background.

Open this feature →
